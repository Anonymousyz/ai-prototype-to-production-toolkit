# How to use this toolkit

## Recommended workflow

1. Describe the AI prototype in one paragraph.
2. Map the business workflow.
3. Complete the readiness checklist.
4. Mark any veto items.
5. Score the prototype.
6. Identify the top five blockers.
7. Run a controlled pilot only if no veto item exists.
8. Reassess after the pilot.

## Minimum evidence package

Before production, prepare:

- workflow map;
- data source and authorization note;
- evaluation set;
- failure case library;
- human review rule;
- access and log design;
- cost estimate;
- rollback plan;
- pilot review memo.

## Suggested roles

| Role | Responsibility |
|---|---|
| Business owner | Defines value and adoption |
| Product / FDE | Maps workflow and delivery plan |
| Engineering | Builds system and logs |
| Data owner | Confirms data source and authorization |
| Risk / Compliance | Reviews boundaries and controls |
| End users | Test real workflow and provide feedback |
