# Launch playbook

## T-7 days

- [ ] Confirm no private data or secrets.
- [ ] Verify README, LICENSE, SOURCES, SECURITY, CONTRIBUTING.
- [ ] Run `python scripts/score_readiness.py examples/sample_assessment.json`.
- [ ] Create a demo screenshot or GIF.
- [ ] Prepare LinkedIn, dev.to, Zhihu/WeChat posts.
- [ ] Prepare 10 feedback requests to relevant people.

## T-1 day

- [ ] Create GitHub public repo.
- [ ] Push `main`.
- [ ] Add description and topics.
- [ ] Enable Issues.
- [ ] Add the workflow template if your token has `workflow` scope, then check GitHub Actions result.
- [ ] Pin repo on GitHub profile.

## Launch day

Recommended timing: Tuesday or Wednesday, US Pacific morning if targeting international audience.

- [ ] Post LinkedIn English announcement.
- [ ] Post Chinese explanation on Zhihu/WeChat.
- [ ] Ask 10 targeted people for feedback, not just stars.
- [ ] Reply to every comment or issue within 24 hours.
- [ ] Capture feedback into GitHub issues.

## T+7 days

- [ ] Publish first release note.
- [ ] Add one example based on feedback.
- [ ] Update roadmap.
- [ ] Cross-link the awesome list.
- [ ] Prepare a second technical post.

## Launch copy

### GitHub description

Toolkit for assessing whether AI prototypes are ready for production deployment: checklists, scorecards, prompts, risk templates, and case examples for enterprise and regulated environments.

### LinkedIn short post

Many AI demos look impressive, but production deployment is different.

I built an open-source AI Prototype-to-Production Toolkit to help teams assess whether an AI prototype is ready for real business workflows. It includes checklists, scorecards, risk templates, NIST/OWASP mappings, prompt templates, fictional examples, and a small scoring script.

If you work on AI deployment, governance, LLMOps, or enterprise AI, feedback is welcome.
