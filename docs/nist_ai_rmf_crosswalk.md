# NIST AI RMF crosswalk

The NIST AI RMF Playbook organizes suggested actions around four functions: **Govern, Map, Measure, Manage**. This toolkit does not claim compliance with NIST AI RMF; it uses the RMF language as a public reference structure.

| Toolkit dimension | Govern | Map | Measure | Manage |
|---|---|---|---|---|
| Business workflow and value | Define ownership and decision rights | Map workflow, stakeholders, context, intended use | Measure baseline and success metrics | Decide pilot / production / stop |
| Data source and boundaries | Assign data owners and policy owners | Map data sources, sensitivity, authorization | Measure data quality and coverage | Apply minimization, masking, isolation, deletion |
| Model output quality and evaluation | Define evaluation accountability | Map use cases, failure modes, out-of-scope requests | Run tests, regression, failure analysis | Improve prompts, retrieval, guardrails, model choice |
| Human review and responsibility | Define who can approve, reject, escalate | Map decisions requiring human judgment | Measure review accuracy, delay, override patterns | Adjust automation level and escalation rules |
| Access, logs, auditability | Define access policy and audit ownership | Map user roles, system actors, model/tool versions | Measure trace completeness and log quality | Investigate incidents and enforce controls |
| Operations, integration, cost | Define operational owner and budget owner | Map dependencies and failure paths | Measure latency, cost, uptime, error rates | Rollback, pause, incident response, vendor review |
| Adoption and improvement | Define product owner and feedback owner | Map user groups and adoption barriers | Measure usage, satisfaction, business outcomes | Iterate, expand, or stop |

## Evidence artifacts

| Evidence artifact | Supports |
|---|---|
| AI system card | Govern / Map |
| Readiness checklist | Map / Measure |
| Evaluation plan | Measure |
| Risk register | Govern / Manage |
| Pilot review memo | Manage |
| Logs and version records | Measure / Manage |
| User feedback summary | Measure / Manage |

## Practical use

When preparing a review memo, use this language:

> This review uses a NIST AI RMF-inspired structure to organize readiness evidence across governance, context mapping, measurement, and risk management. It is not a formal compliance certification.
