# Project status

## Project type

A local-first review toolkit for deciding whether an AI prototype is ready for a controlled pilot or production discussion.

## Current public state

Maintained. Release notes, version tags, and the validation workflow are the source of truth for published versions.

## Intended use

Use it to turn a structured, non-sensitive proposal into a review report with veto conditions, evidence gaps, and next questions.

## Not a replacement for

It does not authorize a launch, replace security review, legal review, domain validation, or accountable human decision-making.

## Feedback and maintenance

Report reproducible defects or documentation gaps through GitHub Issue. Do not include credentials, personal data, or confidential project material.

## Public boundary

Examples are fictional or de-identified. They demonstrate review structure, not a completed deployment or customer outcome.
